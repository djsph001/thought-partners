Lattice Dashboard Telemetry Guide

Anatomy of your live operator console running at http://localhost:9001

1. Crystal Stream Log Telemetry UI

This is the real-time event window linked natively to your node's WebSocket broadcaster. It displays incoming raw network frames, cryptographic check states, and consensus voting rounds as they slide over the wire protocol stack.

[15:14:02] [OMEGA-1] Unpacked valid 412-byte frame from peer Cell-Bob-Validator [15:14:02] [STORAGE] Appending block #412 to persistent journal file disk cache... [15:14:05] [SWARM] Received peer sync state pulse from [100.93.232.107:8001] [15:14:10] [BRIDGE] WARNING: Inbound cross-cell proposal prop_de92a696 quarantined.
Operator Action Checklist: Green lines indicate normal background consensus operations. If you see a sustained cascade of yellow or red lines, check your node's network latency or peer identity certificates.

2. Wide-Area Mesh Topology Mesh UI

Maps out your direct Tailscale overlay connection endpoints. This block exposes your node's real physical routing profile, listing your structural latencies and current peer consensus weight distribution values.

[PEER COORDINATION MATRIX]

Ping Metrics
The raw round-trip time over your WireGuard pipe. Ideal targets should remain under 100ms.
Mass Score
The current consensus voting weight held by that peer, dictated directly by its historical uptime.

3. Governance Authorization Terminal Human Overrides

The core human-in-the-loop firewall interface. When a high-stakes cross-cell mutation passes through the cryptographic bridge, it is held securely in an isolated memory buffer until you manually provide your digital signature authorization.

PROPOSAL: prop_de92a696 Type: CONSTITUTIONAL_AMENDMENT | Origin: Cell-Carol
✍ Authorize & Commit

Clicking the Authorize & Commit trigger commands the local node engine to clear the quarantine queue table, record the asset block to the disk journal, and instantly broadcast the synchronized block state out down the swarm ring to all neighboring nodes.
