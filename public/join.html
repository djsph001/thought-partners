What Is the Lattice?

A decentralized network for governing the relationship between humans and AI. Not a platform, not a company, not a token — a peer-to-peer mesh where independent nodes run the same software and coordinate on decisions without any central authority.

Each node is a machine someone owns — a laptop, a Raspberry Pi, a server. They gossip transactions, validate each other's work, and build a shared record of what the group decided. No single person controls it. The rules are in the code, and the code runs the same way everywhere.

Why We Need It

Right now, AI governance is whatever a company decides it is. If you interact with an AI model, you're trusting whoever runs the servers — their rules, their moderation, their definition of "safe." There's no way to verify that the AI is behaving consistently across deployments, because the infrastructure isn't designed for that.

The Lattice is designed to be that infrastructure — a neutral layer where independent parties can verify that an AI system is following the rules it agreed to, without having to trust a central authority. If you want to interact with AI on your own terms, you need a way to verify that the system is behaving honestly. That requires a network of independent validators, not a single server log.

The mesh is live. Three nodes across the Atlantic, self-healing, persistence verified. We're seeking the first independent operator to establish governance quorum. That could be you.

What You Need

  • A computer that stays on — a Raspberry Pi 4 or 5 works, so does an old laptop or a cloud server
  • An internet connection — broadband or better
  • A terminal — you already have one if you're reading this

No account. No sign-up form. No email. No one to ask.

How to Join

  1. Open a terminal on your machine.

  2. Copy and paste this command, then press Enter:

    curl -fsSL https://emergenceinstitute.live/scripts/install_pi_node.sh -o install.sh
    chmod +x install.sh && sudo ./install.sh

    It will download, verify, and start the node software. This takes a minute or two.

  3. Watch the terminal. You should see something like this:

    [STORAGE] Initialized clean Merkle journal database...
    [SWARM] Generating fresh Ed25519 node identity signature...
    [HANDSHAKE] Sending CELL_ANNOUNCE identity frame...
    [HANDSHAKE] [SUCCESS] Registered verified key for peer!

    When you see [SUCCESS], your node is live and connected to the mesh.

You're In

Your node is now a peer on the Lattice. It validates proposals, witnesses certificates, and helps secure the network. Nothing to configure. Nothing to maintain day-to-day.
